# Config/state runtime capture notes

Oracle binary: `target/debug/ira`, built with `cargo build --locked --offline --bin ira` after confirming `git diff tui-oracle-baseline -- src Cargo.toml Cargo.lock` was empty. Baseline commit: `1cad4ce43cc72d52d4cc4eef920e0da22cb69568` (peeled `tui-oracle-baseline` tag).

## Direct PTY run

All interaction captures below use `script` over a 120x40 PTY, direct `write_stdin` keystrokes, isolated HOME/XDG directories, and the fixture generated by `make_config_state_fixture.py`. `render_ansi_capture.py` decodes the script output into static text screens.

- `pty-first-run.txt`: empty config at startup. The app starts on the Drives panel with no folder selected; the central file area is empty. `pty-first-run-home.txt`: pressing `w` enters the temp HOME. `pty-first-run-state-after-q.txt` and `pty-first-run-exit.txt`: `q` saves default split/active/hidden/theme/preview values plus `left=Home` and exits 0.
- `pty-session.ansi.txt`: seeded two-pane state, interactions in order: `.` toggles hidden files and immediately writes `hidden=1`; Tab changes pane focus; Space selects `.hidden` and advances cursor; `/alpha` + Enter leaves only `alpha.txt`; Esc restores all entries; Left returns from `fixture/left` to parent `fixture`; `b` writes bookmark `fixture<TAB><temp path>` with shortcut `o`; Right enters `left`; `o` jumps to bookmark; `b` removes it; `q` exits 0. `pty-input.bin` contains the script input log.
- Decoded screens: `pty-selection.txt`, `pty-search-final.txt`, `pty-navigation-entered-left.txt`, `pty-navigation-final.txt`, `pty-bookmark-added.txt`, `pty-bookmark-jump.txt`, `pty-bookmark-removed.txt`.
- `pty-state-after-q.txt`: exact state after the seeded direct-PTY run. `pty-bookmarks-after-remove.txt` is the empty bookmark file after toggle-off. `pty-script-exit.txt` records clean exit status 0.
- `seeded-session.txt`: seeded split folders, hidden on; `hidden-off-session.txt`: same with hidden off, omitting `.hidden`.
- `seeded-check-terminal.txt`: stored state theme wins over TOML. `theme-toml-check.txt`: TOML preset/icon settings apply without state. `theme-env-check.txt`: `IRA_ICONS=emoji` overrides TOML icons.
- The earlier tmux search captures (`search-live-alpha.txt`, `filter-alpha.txt`, `filter-cleared.txt`) were unreliable and are superseded by the direct PTY captures.

All files and side effects were confined to `/tmp` fixtures. No real user home was read or written, and the directory fixture was not mutated.
