## Derived behavior list

1. **Launch and initial pane** — `main` checks `--version`/`-V` and `--check-terminal` before TUI init; otherwise it probes terminal image/font capabilities, creates `App`, installs picker/theme capability, initializes TUI, draws once immediately, then ticks every 500 ms. `App::new` loads bookmarks, lists drives, selects the first mounted drive for pane 0 if available, restores session state, loads theme, starts drive polling and asynchronously requests both pane listings. Refs: `src/main.rs:11-69`; `src/app.rs:759-782`.
2. **State file and defaults** — `dirs_next::config_dir()/ira/state`; missing/unreadable file yields defaults. Defaults: unsplit, active pane 0, hidden off, no restored folders, details preview `[3,3]`, no theme, empty folder-size cache. Refs: `src/services/state.rs:18-57,59-73`.
3. **State byte format** — plain UTF-8 `key=value` lines for `split`, `active`, `hidden`, `preview0`, `preview1`, optional `theme`, `left`/`right` as `label<TAB>path`, and repeatable `size=bytes<TAB>items<TAB>on_disk<TAB>complete(0|1)<TAB>epoch<TAB>path`. State save creates parents and ignores create/write failures. Parser trims each line, ignores blank/malformed/unknown keys, uses first `=`, maps non-`1` booleans to false, clamps active to 1 and preview to 3, and drops invalid themes/sizes/folders. Legacy bare folder path is accepted with basename-derived label; empty paths are dropped. Refs: `src/services/state.rs:75-203`.
4. **Restore/persist semantics** — restored split, active index, hidden flag, folders, preview modes, and cached folder sizes are applied before asynchronous relisting; complete size measurements only are serialized. Session state is persisted on normal application exit (`q` or Ctrl-C path) and immediately on theme cycle and hidden toggle. Refs: `src/main.rs:58-73`; `src/app.rs:3943-4025,2976-2982,2284-2292`.
5. **Split and focus** — `+` toggles split. Closing split forces active pane 0. Opening split resets active to 0 and mirrors pane 0 folder/sort/filter into pane 1, clearing pane 1 selection/scroll state rather than resuming its stale or saved right path; it clones settled listing data or starts a separate request if still loading. `Tab` cycles pane 0 → pane 1 when split → Copy Board when open → pane 0; without split/board it stays on current pane. `Tab` also opens offered editable preview text before normal focus cycling; Tab while editing discards changes and advances focus. Refs: `src/handler.rs:290-292`; `src/app.rs:2456-2528`.
6. **Navigation and cursor behavior** — Right enters selected directory, clears filter/search, asynchronously reloads, and resets cursor; on selected file it opens the file and reports open errors in status. Left goes to parent, clears filter/search, and selects the child just left once listing settles; root/parent error does nothing. Up/Down move one row unless scroll-ramp accelerates; Alt+Up/Down call top/bottom and then still move one row. `z` top, `x` bottom. Empty lists clear selection. Refs: `src/handler.rs:245-250,341-359`; `src/app.rs:2206-2282,2435-2453`.
7. **Search/filter interaction** — `/` opens live fuzzy search. Text updates query and selects first result; Up/Down navigate results, Right enters selected result, Enter promotes nonblank query to sticky per-pane filter, Escape cancels and shows all, empty Enter clears the filter. Normal Escape clears a confirmed filter. Sort cycles Name→Size→Modified→Kind on active pane; reorders while preserving selected file identity and recomputes confirmed-filter indices. Refs: `src/handler.rs:184-209,266-268,326-328`; `src/app.rs:2294-2325,3748-3885`.
8. **Hidden entries and preview state** — `.` toggles hidden entries, relists both panes, persists immediately. `v` cycles active pane Details→Column→Grid→Off→Details, with modes per pane and saved as numeric 3/1/2/0 respectively. Refs: `src/handler.rs:274-275,320-322`; `src/app.rs:1881-1904,2976-2982`; `src/services/state.rs:28-33,44-48,99-100`.
9. **Bookmarks format and shortcuts** — `~/.config/ira/bookmarks`, one `label<TAB>path` per line; read preserves order, skips blank lines, accepts bare paths with basename label, missing/unreadable is empty. `b` toggles current folder by exact path and writes immediately (including an empty file after removal). Shortcuts assigned in keyboard order, skipping common-folder keys `w e r t y u i` and reserved keys `q c z x b m v`; sequence available is `o p a s d f g h j k l n`. If exhausted, error text is `No free bookmark shortcut available (a-p are taken)`. Refs: `src/services/bookmarks.rs:6-75`; `src/handler.rs:269-270,329-339`; `src/app.rs:3887-3937`.
10. **Theme and icon config** — `theme.toml` in the same config directory; malformed/unreadable TOML falls back to defaults. Built-in preset precedence is persisted session theme > valid TOML preset > default. `\` cycles preset, applies retained per-key TOML overrides, raises `Switched to <label>`, and persists immediately. Icons are not persisted: `IRA_ICONS` override > TOML icons > font/capability auto-detection. `--check-terminal` reports truecolor/icon/font/image-protocol/cell-size/theme-file diagnostics and exits before entering TUI. Refs: `src/theme/mod.rs:411-445,481-601,617-619`; `src/main.rs:21-24,93-176`; `src/handler.rs:283-285`.
11. **Global keys/mode precedence relevant to navigation** — Ctrl-C quits in every mode; Ctrl-A toggles select-all except rename; mode-specific editors/prompts and modal dialogs intercept keys before normal navigation. In search mode only mapped text/nav keys are processed. `*` help closes on any key; error/info/confirm dialogs and deletion progress each have their own any-key/confirm handling. Refs: `src/handler.rs:18-225,228-362`.

## Live runtime evidence and limits

Built the oracle commit from `git archive tui-oracle-baseline` into `/tmp/ira-blind.dglny4` using the existing repository Cargo target directory (the first isolated target attempt failed with disk quota). Ran the resulting `target/debug/ira` in a 120x40 tmux PTY with an isolated fixture (`a.txt`, `.hidden`, `subdir/b.txt`) and temporary `HOME`/`XDG_CONFIG_HOME`. A live capture showed the 120x40 first-run chrome: Drives, Common folders, Bookmarks, Actions, a blank file-list region during startup, and footer hints including `.` hidden, `,` sort, `v` preview, `b` bookmark, and `*` keybindings. The app process was live (`pane_dead=0`). Follow-up key/exit captures were inconsistent/blank in this shared tmux environment and produced no attributable saved `state` file; therefore no dynamic claim is made for persistence bytes or key effects. Those claims above are source-derived and require a clean repeat capture. No destructive operation was run.

## Absence claims / uncertainty

- State service recognizes no per-directory preferences, keymap overrides, or theme settings besides `theme.toml`/preset/icons described above; this is based on exhaustive match arms in `parse_state` plus the theme TOML struct, not a global repo-wide proof of no other configuration input.
- No standalone config file controls navigation state; bookmarks and session state are the two persistence files found in the claimed source set.
- Bookmark/state paths use `dirs_next::config_dir`; the literal `~/.config` wording is Linux-specific. macOS/Windows concrete locations were not dynamically checked here.
- First live screen was observed, but interactive runtime effects and exit status could not be captured reliably due shared tmux session interference; a clean uniquely named PTY rerun is needed.
